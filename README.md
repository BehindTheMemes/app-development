Ответ от агента:

Сложность данной функции `is_adult` следующая:

*   **Временная сложность:** $O(1)$ (константная). Функция выполняет фиксированное количество операций (сравнение и возврат значения), которые не зависят от величины входного числа `age`.
*   **Пространственная сложность:** $O(1)$ (константная). Функция не использует дополнительные структуры данных, размер которых рос бы вместе с входными данными.

Ответ:

Функция `is_adult()` имеет временную сложность $O(1)$, так как выполняет фиксированное количество операций независимо от значения age. Память, используемая функцией, также составляет $O(1)$, поскольку дополнительные структуры данных не создаются.

Квадратичный риск может возникнуть не в самой функции, а при её массовом вызове внутри двойного цикла: например, если проверять возраст каждой пары пользователей, количество вызовов составит $O(n²)$.

Если задача требует проверить пользователей на совпадения или сгруппировать их по определённому признаку, вместо вложенного цикла следует использовать set или dict. Эти структуры позволяют выполнять поиск в среднем за $O(1)$ и тем самым снизить типичный риск с $O(n²)$ до $O(n)$.
